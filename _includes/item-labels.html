Nothing renders when none applies. Both variables are reset on every call because Jekyll includes share the page scope, so a value assigned for one item would otherwise reach the next. The marker renders only while the event still lies ahead: site.time is the build instant, normalised to midnight so an event happening today still counts, and both sides resolve in Asia/Tokyo because _config.yml sets timezone. The year shows only when the event is not in the build's year, so a date a stated year away (来年, ２０２７年) cannot read as this year's. Each label is a chip; the space between two chips stays in the text, so a screen reader still hears two words. It is output with {{ " " }} because Liquid renders an if block holding only whitespace as nothing. include.on_until, a closing date, shows "On now" in the marker's place until that day; a post never has both dates, and the date goes through | date first so an unquoted YAML date compares like a string.
